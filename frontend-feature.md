## Peran

Front-End Developer bertanggung jawab atas bagian antarmuka (user interface) dari aplikasi, yaitu semua yang dilihat dan digunakan langsung oleh pengguna. Tujuannya adalah membuat tampilan yang menarik, mudah dipakai, dan responsif di berbagai ukuran layar.

## Kontribusi

- Merancang tampilan halaman utama dan struktur layout aplikasi.
- Membuat komponen antarmuka seperti navigasi, form, tombol, dan kartu informasi menggunakan HTML, CSS, dan JavaScript.
- Memastikan tampilan responsif agar nyaman diakses dari desktop maupun perangkat mobile.
- Menghubungkan antarmuka dengan fitur backend melalui API (fetch data, kirim form, tampilkan hasil).
- Menjaga konsistensi desain (warna, tipografi, jarak) di seluruh halaman.
- Melakukan pengujian tampilan dasar dan memperbaiki bug pada sisi antarmuka.

## Teknologi yang Digunakan

- HTML5, CSS3, JavaScript
- Visual Studio Code
- Git dan GitHub untuk kolaborasi
