# Backend Feature

## Tentang File Ini
File ini dibuat oleh Back-End Developer sebagai dokumentasi peran, 
tanggung jawab, dan kontribusi dalam repository tim.

## Peran: Back-End Developer

### Deskripsi Peran
Back-End Developer bertanggung jawab atas bagian server-side dari aplikasi.
Fokus utamanya adalah membangun logika bisnis, memproses data, mengelola
database, serta menyediakan API (*Application Programming Interface*) yang
nantinya dikonsumsi oleh bagian front-end.

### Tanggung Jawab
1. **Membangun Logika Bisnis**: mengimplementasikan aturan dan proses
   utama aplikasi di sisi server.
2. **Mengelola Database**: mendesain skema database, serta memastikan
   proses penyimpanan, pengambilan, dan pembaruan data berjalan aman
   dan efisien.
3. **Membuat API**: menyediakan endpoint yang dapat diakses oleh
   front-end (misalnya REST API) untuk bertukar data.
4. **Keamanan & Validasi Data**: memvalidasi input dari pengguna dan
   mencegah potensi celah keamanan seperti SQL Injection.
5. **Integrasi dengan Front-End**: berkoordinasi dengan Front-End
   Developer agar data yang dikirim/diterima API sesuai kebutuhan.
6. **Testing**: melakukan pengujian pada fitur backend sebelum digabungkan
   ke branch utama.

### Teknologi yang Digunakan
- Bahasa/Runtime: Node.js / Python / Java / PHP
- Framework: Express.js / Django / Spring Boot / Laravel
- Database: MySQL / PostgreSQL / MongoDB
- Testing: Postman / Jest
